# Резервные копии и перенос данных

Экспорт: «Настройки → Экспортировать базу». Создаётся согласованный снимок через
SQLite backup API; копирование открытого файла средствами обычного файлового
копирования не используется. Файл можно хранить отдельно от программы.

Импорт: выбрать файл в «Настройки → Восстановить из файла» и подтвердить замену.
Проверяются заголовок SQLite, целостность, внешние ключи, совместимая схема,
структура устройств/правил/расписаний и поддерживаемые парольные хеши. Известные
старые ревизии обновляются миграциями в проверочной копии до изменения живой базы.
Копия с неизвестной новой схемой отклоняется. Максимальный размер импорта — 2 ГБ.
Передача и обработка используют временные файлы, а не копию всей базы в памяти.

До замены автоматически создаётся страховочная копия:
`%LOCALAPPDATA%\SmartHome\data\backups\before-restore-....db`.
Запросы и фоновые задачи на время замены проходят через общий барьер. После
восстановления удаляются сессии, сбрасывается якорь симуляции и вычисляются
следующие запуски расписаний без воспроизведения пропущенных событий.
Нужен вход с именем/паролем из выбранной копии.

На новом компьютере сначала запустите приложение и создайте локального
пользователя, затем импортируйте копию. Эти временные данные будут заменены.
Одна папка программы или EXE не переносит базу из профиля пользователя.

Если повреждённая база не позволяет запустить приложение, завершите SmartHome,
сохраните весь старый каталог `data` под другим именем и создайте новый `data`.
Поместите проверенную ранее экспортированную копию в него как `smart_home.db`.
Это ручное восстановление выполняют только при остановленном приложении;
старый каталог сохраняет исходные данные и журналы для восстановления.
