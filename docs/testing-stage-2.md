# Проверка этапа 2

Среда: Linux, Python 3.12.14, Node.js 24.22.1, Vite 7.3.8, Chromium/Playwright.
Windows EXE не собирался: это этап 7.

## Автоматические проверки

- `python -m pytest backend/tests -q`: **106 тестов успешно**.
- `ruff check backend`, `ruff format --check backend`: успешно.
- `python -m pip check`: конфликтов зависимостей нет.
- `npm run build`: TypeScript и production-сборка frontend успешны.
- `git diff --check`: успешно.

Сохранены проверки этапа 1; тест неизвестного маршрута теперь использует
`/api/unimplemented`, поскольку `/api/devices` уже реализован.
Новых зависимостей для этапа 2 не добавлено.

Дополнительно проверены:

- CRUD комнат и устройств, счётчики, фильтры и пагинация.
- Уникальность названий комнат и корректные HTTP 404/409/422/503.
- Все команды шести типов устройств, границы значений и строгие типы.
- Запрет лишних параметров, команд другого типа и прямой записи состояния.
- Сохранение команды в SQLite и восстановление при новом экземпляре приложения.
- Ручное движение с UTC-временем, показания датчиков, source событий.
- Изменение номинальной мощности розетки без изменения накопленной энергии.
- Запрет удаления непустой комнаты; перенос устройств с сохранением состояния.
- Запрет переноса устройства или комнаты назначения между разными домами.
- Удаление устройства с удалением текущего состояния и сохранением событий.
- Ошибка команды записывает событие, не меняя состояние и его время.
- Сбой записи события откатывает изменение состояния.
- Одновременные команды в независимых сессиях не теряют изменения разных полей.
- Отключённый адаптер возвращает ошибку; адаптер не изменяет входной снимок.
- Setup создаёт пользователя, дом и четыре комнаты; повторный запуск не
  дублирует данные и сохраняет изменения пользователя.
- Хеш пароля имеет уникальную соль, неверные учётные данные отклоняются.
- CLI не выводит пароль; несовпадение паролей не создаёт базу.
- Неконечные числа во входном JSON возвращают 422, а не ошибку сериализации 500.

## Реальные процессы и браузер

Backend и Vite запущены отдельными процессами. В облачной среде использованы
свободные локальные порты 8012 и 5174; штатные дефолты проекта — 8000 и 5173.
Для данных использовался отдельный проверочный каталог вне репозитория.

- Chromium загрузил страницу React и получил успешный `/api/health` через Vite.
- Через настоящий HTTP выполнены создание комнаты и трёх устройств, команды
  лампы, датчика движения и розетки, чтение состояний и счётчиков.
- Некорректная яркость вернула 422 и не изменила состояние.
- Удаление непустой комнаты вернуло 409.
- После остановки и нового запуска серверного процесса восстановлены цвет лампы,
  состояние движения и питание розетки из той же SQLite.
- Проверен OpenAPI с типизированными состояниями и ошибками API.
- Проверочные устройства и комната удалены через API, журнал сохранён.
- Ошибок JavaScript и внешних запросов страницы не обнаружено.
