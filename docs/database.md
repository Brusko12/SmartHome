# База данных

SQLite + SQLAlchemy 2; внешние ключи включаются на каждом соединении.
Целочисленные PK с AUTOINCREMENT не переиспользуются после удаления.
Даты в Python имеют UTC timezone, в SQLite хранятся в UTC.

| Модель | Связи и назначение |
|---|---|
| User | Локальный пользователь, username и хеш пароля; владелец домов |
| Home | Владелец, имя, IANA timezone, проверенные настройки |
| Room | Дом, название, иконка; имя уникально внутри дома |
| Device | Дом, обязательная комната, тип, адаптер, параметры, необязательная интеграция |
| DeviceState | Одно текущее состояние на устройство; source и отдельный якорь симуляции |
| Automation | Дом, scenario/rule, триггер, условия, упорядоченные действия, последний запуск |
| Schedule | Дом, время/дни, сценарий либо действия, предыдущий и следующий запуск |
| EventLog | Дом, тип/источник/статус, описание, снимки и дополнительные данные |
| Integration | Метаданные будущих адаптеров; реальные интеграции отсутствуют |
| UserSession | Служебные сессии: пользователь, хеши токенов, срок действия |

Составные FK запрещают устройство в комнате/интеграции другого дома и расписание
на автоматизацию другого дома. Удаление зависимого дома/пользователя запрещено.
Комната с устройствами удаляется только после явного переноса, без удаления устройств.
Удаление устройства каскадно удаляет текущее состояние, сохраняет события с
обнулённым FK и записанными ID/именем/типом в details. Используемая расписанием
автоматизация защищена от удаления.

JSON проверяется при записи ORM и дополнительно типовыми Pydantic-схемами команд,
состояний, правил и расписаний. Изменения JSON заменяют объект целиком.
Ссылки в JSON-действиях проверяются сервисом; удалённая обязательная цель даёт
ошибку с результатами выполненных/пропущенных действий, необязательная пропускается.

Миграции:

- 0001 — девять основных таблиц.
- 0002 — настройки дома.
- 0003 — якорь симуляции отдельно от времени изменения состояния.
- 0004 — служебные сессии авторизации.

При старте применяется `upgrade head`, без сброса данных и `create_all()`.
Демонстрация создаётся только по выбору пользователя, атомарно и идемпотентно.
Путь и правила переноса описаны в README и backup.md.
