# Отчёт проверки

Дата: 13 ноября 2026. Среда: Linux, Python 3.12.14, Node.js 24.22.1,
Chromium; дополнительно GitHub Actions Windows Server 2025, Python 3.12.10.
Ручная пользовательская Windows 10/11 в текущей среде недоступна.

## Автоматизированные проверки

- `python -m pytest backend/tests -q`: **142 passed**.
- Ruff: проверка кода и форматирования backend, launcher и scripts проходит.
- `npm run build`: TypeScript и production-сборка Vite проходят.
- `pip check`: конфликтов зависимостей нет.
- Настоящий source-launcher: регистрация, SQLite, статический React, команда лампе,
  повторный запуск без второго сервера, штатная остановка и сохранение состояния
  после перезапуска — проходят.
- Контрольная Linux-сборка PyInstaller: тот же сценарий проходит при ограниченном
  PATH без venv и отключённой системной базе часовых поясов. Используется
  включённый tzdata. Это не является Windows-приёмкой.

Backend-тесты покрывают миграции и повторную инициализацию без потери данных,
связи и ограничения SQLite, CRUD комнат/устройств, проверку команд и транзакций,
сохранение состояний, последовательности сценариев, триггеры/условия/циклы,
расписания и DST, симуляцию и перезапуск, сессии/CSRF/Origin/пароли,
историю, настройки, демонстрацию, проверку/восстановление копий и статический UI.

Отдельная регрессия проверяет запуск без зависимости от HTTPS-конфигурации
системы: probe работает напрямую с локальным HTTP-сервером, проверяет
идентификатор экземпляра и различает работающий и полностью готовый сервер.

## Браузерная проверка

В Chromium с реальным API и SQLite проверены: первоначальная настройка,
демонстрационный дом, устройства и панель, экспорт базы, изменение дома,
подтверждённый импорт, отзыв сессии и повторный вход, фильтры истории,
диагностика, выход на мобильной ширине. Ошибок JavaScript и запросов
на внешние адреса во время сценария не зарегистрировано.

Тот же сценарий пройден через статический frontend в PyInstaller-сборке,
включая кнопку «Завершить SmartHome». Серверный процесс завершился с кодом 0.
