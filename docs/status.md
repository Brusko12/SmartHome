# Статус реализации

Этапы 1–6 реализованы: архитектура, SQLite/миграции, комнаты и устройства,
интерфейс, сценарии/правила, расписания/симуляция, локальная авторизация,
история, настройки, резервные копии и диагностика.

Этап 7: подготовлены launcher, раздача React через FastAPI, PyInstaller spec,
Windows-скрипт, проверка настоящего процесса и GitHub Actions workflow.
Windows EXE пока не собран и не проверен в Windows-среде.

Этап 8: локальные backend, frontend и браузерные проверки выполняются;
приёмка чистой Windows и готового Windows-дистрибутива без интернета не выполнена.
Проект не объявляется полностью завершённым до этих проверок.

## Поведение и ограничения

- Один локальный пользователь, с возможностью расширения моделей в будущем.
- Все устройства виртуальные. Физические интеграции не реализованы.
- Фоновые задачи работают только при открытом приложении. Пропущенные при
  закрытии расписания не догоняются. Для уже заявленного запуска автоматического
  повтора после аварии нет; между фиксацией запуска и действием возможен пропуск.
- Симуляция не учитывает время, пока приложение закрыто.
- Cookie-сессия действует до 12 часов; смена пароля/импорт завершает сессии.
- Закрытие браузерной вкладки не завершает сервер. Launcher предоставляет
  явную кнопку завершения на странице состояния системы.
- Для разработки нужны Python/Node; готовая Windows-папка должна включать всё.
- Исторические отчёты этапов 1–2 описывают состояние на тех этапах;
  актуальные возможности описаны в README и текущем отчёте проверки.
