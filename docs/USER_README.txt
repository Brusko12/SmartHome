SmartHome — локальное управление умным домом (Windows 10/11, 64-bit)

ЗАПУСК
1. Распакуйте всю папку SmartHome-Release в постоянное место.
2. Дважды нажмите SmartHome.exe. Не отделяйте EXE от папки resources.
3. Дождитесь открытия стандартного браузера.
4. Создайте локального пользователя, задайте пароль и название дома.
5. При желании создайте демонстрационный дом предложенной кнопкой.

Python, Node.js, Git, IDE и интернет для работы готовой сборки не нужны.
Можно создать ярлык SmartHome.exe на рабочем столе средствами Проводника.
Повторный запуск открывает уже работающий экземпляр.

ЗАВЕРШЕНИЕ
Откройте «Состояние системы» и нажмите «Завершить SmartHome».
Закрытие вкладки браузера само по себе не останавливает сервер и расписания.
При полностью закрытом приложении расписания не выполняются.

ДАННЫЕ И ПЕРЕНОС
База хранится в профиле пользователя:
%LOCALAPPDATA%\SmartHome\data\smart_home.db
Перемещение папки программы не переносит пользовательские данные.
На старом компьютере: Настройки → Экспортировать базу.
На новом: запустите приложение, выполните первоначальную настройку,
затем Настройки → Восстановить из файла и подтвердите замену данных.
После импорта войдите с именем и паролем из резервной копии.
Перед восстановлением автоматически создаётся страховочная копия в data\backups.

Физические устройства, MQTT, Home Assistant и облачные сервисы не подключаются.
Все устройства виртуальные; их состояния, сценарии и история сохраняются в SQLite.

Если запуск не удался, сообщение укажет журнал SmartHome.log в каталоге данных.
