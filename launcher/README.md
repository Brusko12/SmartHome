# Launcher

`main.py` запускает один FastAPI-процесс на свободном порту 127.0.0.1,
проверяет API и открывает стандартный браузер. Повторный запуск открывает
работающий экземпляр. Блокировка, PID и случайный идентификатор защищают
от ошибочного подключения к чужому серверу на повторно занятом порту.

Исходники: `python launcher/main.py`, после сборки frontend. Для автоматической
проверки: `--no-browser --data-dir <абсолютный путь>`. Данные и журнал находятся
в постоянном каталоге пользователя. В интерфейсе «Состояние системы» доступно
«Завершить SmartHome». Закрытие вкладки сервер не останавливает.

Сборка PyInstaller: [инструкция Windows](../docs/windows-build.md).
