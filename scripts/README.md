# Скрипты сборки и проверки

`build_windows.ps1` выполняется на Windows: тесты backend, npm ci и сборка
frontend, PyInstaller, проверка настоящего EXE, затем архивирование папки.
При ошибке проверки новый архив не создаётся.

`check_release.py <путь к EXE или launcher/main.py> --report <путь к JSON>`
проверяет статический интерфейс, регистрацию, управление лампой, повторный
запуск, остановку и сохранение состояния после перезапуска. Использует отдельный
временный каталог данных; не затрагивает пользовательскую базу. Для EXE очищает
Python-переменные и ограничивает PATH, чтобы не зависеть от установленного Python.

Все команды запускайте из корня проекта. Подробности: [Windows](../docs/windows-build.md).
